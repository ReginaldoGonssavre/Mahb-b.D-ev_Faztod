# Guia de Contribuição para MAHBUB.dev

Bem-vindo ao projeto MAHBUB.dev! Agradecemos o seu interesse em contribuir. Este guia irá ajudá-lo a começar e a garantir que suas contribuições sejam eficazes e alinhadas com os padrões do projeto.

## 🤝 Como Contribuir

Existem muitas maneiras de contribuir para o MAHBUB.dev, não apenas com código:

*   **Relatar Bugs:** Ajude-nos a identificar e corrigir problemas.
*   **Sugerir Funcionalidades:** Compartilhe suas ideias para novas funcionalidades.
*   **Melhorar a Documentação:** Contribua para tornar nossa documentação mais clara e completa.
*   **Escrever Código:** Desenvolva novas funcionalidades, corrija bugs ou refatore o código existente.
*   **Revisar Código:** Ajude a revisar Pull Requests de outros contribuidores.
*   **Suporte à Comunidade:** Responda a perguntas e ajude outros usuários.

## 🚀 Começando

1.  **Fork o Repositório:** Faça um fork do repositório `Mahb-b.D-ev_Faztod` para sua conta GitHub.
2.  **Clone o Repositório:** Clone o seu fork para sua máquina local:
    ```bash
    git clone https://github.com/SEU_USUARIO/Mahb-b.D-ev_Faztod.git
    cd Mahb-b.D-ev_Faztod
    ```
3.  **Crie uma Nova Branch:** Crie uma branch para sua contribuição. Use um nome descritivo (ex: `feat/nova-funcionalidade`, `fix/bug-autenticacao`, `docs/melhoria-readme`).
    ```bash
    git checkout -b feat/sua-nova-funcionalidade
    ```
4.  **Configure o Ambiente:** Siga as instruções no `README.md` para configurar seu ambiente de desenvolvimento.
5.  **Faça Suas Alterações:** Implemente suas mudanças, adicione testes (se aplicável) e atualize a documentação.
6.  **Teste Suas Alterações:** Certifique-se de que suas alterações não introduzem novos bugs e que todos os testes existentes passam.
7.  **Commit Suas Alterações:** Escreva mensagens de commit claras e concisas, seguindo as [Convenções de Commit](#-convenções-de-commit).
    ```bash
    git commit -m "feat: Adiciona nova funcionalidade X"
    ```
8.  **Push para o seu Fork:**
    ```bash
    git push origin feat/sua-nova-funcionalidade
    ```
9.  **Abra um Pull Request (PR):** Vá para o repositório original no GitHub e abra um Pull Request da sua branch para a branch `main` (ou `develop`, dependendo do fluxo de trabalho). Descreva suas alterações detalhadamente.

## 📝 Convenções de Commit

Por favor, siga as [Convenções de Commit](https://www.conventionalcommits.org/en/v1.0.0/) para suas mensagens de commit. Isso ajuda a manter o histórico do projeto limpo e legível.

Exemplos:

*   `feat: Adiciona autenticação de usuário via Supabase`
*   `fix: Corrige erro de carregamento de dados no dashboard`
*   `docs: Atualiza seção de instalação no README`
*   `refactor: Otimiza função de processamento de imagem`
*   `chore: Atualiza dependências de desenvolvimento`

## 📏 Padrões de Código

*   **Python:** Siga o PEP 8. Use ferramentas como `ruff` ou `flake8` para linting.
*   **JavaScript/TypeScript:** Siga as diretrizes do ESLint e Prettier configuradas no projeto.
*   **Formatação:** Use Prettier para formatar o código automaticamente.

## 🧪 Testes

Sempre que possível, adicione testes unitários e de integração para suas alterações. Isso garante a estabilidade e a qualidade do código.

## 💬 Código de Conduta

Ao participar deste projeto, você concorda em seguir nosso [Código de Conduta](CODE_OF_CONDUCT.md).

Obrigado por contribuir para o MAHBUB.dev!
