# Maḥbūb Agent Framework

This framework provides a structure for building and orchestrating AI agents.

## Components

- **Core:** Contains the core transformer-based processing unit.
- **MCP:** Manages the agent's memory and state (Model Context Protocol).
- **Agent:** The base agent implementation.
- **Communication:** Handles multi-agent communication.
- **Autonomy:** Provides autonomous capabilities like policy management and self-modification.
